## Use Case

Use this endpoint to track voter turnout on polling day in (close to) real time. It is ideal for powering a notification service (for the latest headline number), visualising turnout by seat, or charting turnout over the course of the day. Every figure is split into overall, early and ordinary turnout.

There are two endpoints:

- **`/vto/latest`**: the newest snapshot for the state, every Parliament seat and every DUN seat. Poll this for a live view.
- **`/vto`**: one level (Parliament, DUN or polling district) for one 5-minute slot. Use this to build a time series or to go down to polling district (DM) level.

## Data Note

On 14 November 2026, polling day for the 16th Melaka state election, the Election Commission (SPR) published real-time voter turnout via dashboard.spr.gov.my, made possible by the introduction of [digital voter registration](https://www.kosmo.com.my/2026/11/13/spr-teruskan-sistem-ocr-va-papar-bilangan-pengundi-masa-nyata/) at polling centres. We launched this endpoint the same day, and will maintain it for as long as SPR continues to publish the data.

Responses are cached for 30 seconds (other endpoints cache for 300 seconds), and a new snapshot arrives every 5 minutes, so polling once a minute is plenty.

A successful `200 OK` response returns a JSON object with these keys:

<FieldTable fields={[
  { name: "timestamp", type: "string", description: "Time of the snapshot in the Election Commission (SPR) feed, in Malaysia time (MYT), e.g. '2026-11-14 08:25:52'." },
  { name: "slot", type: "string", description: "The 5-minute slot this snapshot belongs to, as HHMM in MYT (the timestamp rounded down), e.g. '0825'. Pass it as time to /vto to fetch other levels for the same moment." },
  { name: "state", type: "object", description: "A turnout unit (see below) for the whole state." },
  { name: "parlimen", type: "object", description: "One turnout unit per Parliament seat, keyed by seat name, e.g. 'P.134 Masjid Tanah'." },
  { name: "dun", type: "object", description: "One turnout unit per DUN seat, keyed by seat name, e.g. 'N.01 Kuala Linggi'." },
]} />

Polling district (DM) figures are not included here, to keep the response small. Use Step 2 for those.

---

**Turnout unit**: every state, seat and polling district has the same fields. The *abs* fields are votes cast, the *vto* fields are turnout percentages, and the *electorate* fields are the denominators those percentages are based on.

<FieldTable fields={[
  { name: "overall_abs", type: "integer", description: "Total votes cast: early, ordinary and postal." },
  { name: "overall_vto", type: "float", description: "Overall turnout as a percentage to 2 decimal places (null if the electorate is 0)." },
  { name: "overall_electorate", type: "integer", description: "All registered voters, from the final voter roll. Includes postal voters, so it is slightly larger than awal_electorate + biasa_electorate." },
  { name: "awal_abs", type: "integer", description: "Early votes cast (awal = police, army and others who voted before polling day)." },
  { name: "awal_vto", type: "float", description: "Early-voter turnout as a percentage (null if there are no early voters)." },
  { name: "awal_electorate", type: "integer", description: "Registered early voters. 0 for DUNs (and their pseudo-districts) with no early voters; null for regular polling districts." },
  { name: "biasa_abs", type: "integer", description: "Ordinary votes cast on polling day (biasa = ordinary)." },
  { name: "biasa_vto", type: "float", description: "Ordinary-voter turnout as a percentage (null if there are no ordinary voters)." },
  { name: "biasa_electorate", type: "integer", description: "Registered ordinary voters (null for the early-voting pseudo-districts)." },
]} />

```json

  "biasa_abs": 712,
```

## Step 2: Get a time slot

<EndpointCard method="GET" url="https://api.electiondata.my/v1/vto" params={[
  {
    name: "election",
    type: "string",
    required: true,
    description: "Election identifier, e.g. 'mlk-se16'. Same format as in Step 1."
  },
  {
    name: "level",
    type: "string",
    required: true,
    description: "One of 'parlimen', 'dun' or 'dm' (polling district)."
  },
  {
    name: "time",
    type: "string",
    required: true,
    description: "The 5-minute slot as HHMM in Malaysia time, from '0800' until '1800' (18:00 MYT, when polls close), e.g. '0805' or '1430'."
  }
]} />

Slot `0800` is the pre-polling baseline: it contains early votes only, with every ordinary vote still at 0. Live slots start at `0805`. A slot that hasn't happened yet returns `404 Not Found`. A missing parameter, a `level` that isn't one of the three options, or a `time` that isn't HHMM in 5-minute steps returns `400 Bad Request`.
